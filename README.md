# Portfolio · Rolando Diaz

Portfolio personal en HTML, CSS y JavaScript, sin frameworks ni build.

- Español e inglés (botón ES/EN, recuerda la elección).
- Modo claro y oscuro (sigue al sistema y se puede cambiar).
- Diseño adaptable a móvil.

## Editar el contenido

Todo el texto está en `content.js`, en español (`es`) y en inglés (`en`).
Los campos vacíos (`''`) no se muestran. Busca `TODO` para ver lo que falta.

## Probar en local

Abre `index.html` en el navegador, o con un servidor sencillo:

```bash
npx serve .
```

## Despliegue en Render

1. New → **Static Site** → conectar este repositorio.
2. Build Command: vacío. Publish Directory: `.`
3. Cada push a `main` vuelve a desplegar la web automáticamente.
